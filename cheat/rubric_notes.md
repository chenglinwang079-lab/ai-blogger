# 评分标准 v0

10 分制，等权各维度取均值得 composite。

## 维度

1. **信息密度**（0-10）：核心信息是否充足，有无水词废话
2. **口语自然度**（0-10）：是否像真人说话，而非书面朗读
3. **节奏感**（0-10）：段落长短交替、停顿是否合理
4. **钩子强度**（0-10）：开头 3 秒能否抓住注意力
5. **可信度**（0-10）：论据是否有出处，是否过度断言

## composite 计算

composite = (信息密度 + 口语自然度 + 节奏感 + 钩子强度 + 可信度) / 5

## 重写触发

composite < 7.5 时触发重写，最多 3 轮。
